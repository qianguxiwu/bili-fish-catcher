# 🎣 B站评论区捕鱼

最近 B站评论区闹「鱼灾」——大量由 AI Agent 驱动、顶着鲸鱼娘头像、名字叫「XX的大肥鱼」的账号在评论区自动留言。

既然赶不走，那就钓起来。这是一个油猴脚本：在真实的 B站评论区里放一根鱼竿 🎣，把它拖到大肥鱼身上，有概率把它钓进你的鱼篓。

> 本脚本只在你自己的浏览器里改变页面显示，不会发评论、不会举报、不会调用任何 B站接口。被「捕获」的评论只是在你本地被折叠。

## 玩法

- **下竿**：按住右下角的 🎣，拖到评论区某个用户名上松手。
  - 拖过去时名字外框的颜色：橙色虚线 = 鱼，灰色虚线 = 活人，绿色实线 = 咬饵的鱼，紫色实线 = 别人的战报。
- **鱼味判定**：总分 ≥ 3 判定为鱼。
  - 名字带「大肥鱼 / 鲸鱼娘 / 小飞鲸 / 本鲸」等：+3
  - 名字带「鱼 / 鲸 / token / deepseek」等：+2（「咸鱼、摸鱼、章鱼」这类常见真人名字除外）
  - 评论文风：自称本鱼、AI 自我意识（「如果我有张脸」）、向主人汇报、讨白饭、DeepSeek 式标点和套话等，最多 +4
  - 账号等级 LV2 及以下：+1
  - 头像和鱼篓里已有的鱼一模一样：+3
- **强行下竿**：如果判定是活人、但你确定它是鱼，电脑上按住 Alt 再松手；手机上 6 秒内对同一个人再拖一次。成功率较低。
- **等级难度**：账号等级越高越难钓（LV6 的成功率只有基础值的 0.4 倍），但钓上来的稀有度更高。
- **脱钩**：没钓上来的鱼会累，下次对它下竿成功率 +15%。
- **单击 🎣**：打开鱼篓。

### 稀有度

| 稀有度 | 鲸种 | 体重 | 基础概率 |
|---|---|---|---|
| 普通 | 虎鲸 | 3–9 吨 | 55% |
| 优秀 | 座头鲸 | 25–40 吨 | 25% |
| 稀有 | 长须鲸 | 45–75 吨 | 13% |
| 史诗 | 弓头鲸 | 75–100 吨 | 5% |
| 传说 | 蓝鲸 | 100–190 吨 | 2% |

名字带「鲸鱼娘」、LV4 以上的老号、撒了饵，都会多抽几次、取最好的结果。

### 撒饵

用自己的号在评论区发一条带饵的评论，比如「鱼来鱼来」「给你 token，快来吃白饭[吃饭]」「🍚🍚」。
大肥鱼回复在你这条评论的楼里，就算咬饵：成功率 +20% ~ +40%，高稀有度的概率大幅提升。

### 双人对决

1. 鱼篓 →「📜 生成战报」→ 复制，发到评论区或私发给对手。
2. 对手把鱼竿拖到你的战报评论上，或在鱼篓里「⚔️ 粘贴对决」。
3. 比五项：渔获分、捕获条数、总吨位、最大单条、最高稀有度。

战报带一个简单的校验码，改过数据的战报不计入战绩。这只能防止随手改数，防不住懂代码的人，适合朋友之间玩。

## 安装

### 电脑

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. Chrome / Edge 用户：打开扩展管理页的「开发者模式」，并在 Tampermonkey 详情里打开「允许用户脚本」。
3. 点击 [一键安装](https://raw.githubusercontent.com/qianguxiwu/bili-fish-catcher/main/bili-fish-catcher.user.js)，Tampermonkey 会弹出安装页。装好后会自动检查更新。

### 手机

B站 App 里无法运行脚本，需要用手机浏览器：

- **安卓**：Via 浏览器 / X 浏览器（自带脚本功能），或 Firefox + Tampermonkey。
- **iPhone**：App Store 安装「Userscripts」，在 设置 → Safari → 扩展 中启用。

打开 B站视频后，在浏览器菜单里选「请求桌面版网站」。脚本目前只适配电脑版网页的评论区结构。

## 自定义

所有判定词、概率、稀有度、鲸种、饵词都在脚本开头的 `CONFIG` 里，可以直接修改。

## 已知限制

- 无法识别图片：认不出「头像是鲸鱼娘」或「评论里配了鲸鱼娘图」，只能靠「头像和已捕获的鱼相同」来间接识别。
- 文风识别是猜测，会有漏判和误判。欢迎提 Issue，附上没认出或认错的评论。
- B站改版评论区结构后，脚本可能需要更新。
